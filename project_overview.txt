John Hay Hotels - Forest Wing Guest Feedback System
===================================================

1. FONTS USED
---------------------------------------------------
- Great Vibes (Script): Used for the main hotel branding and elegant headers.
- Playfair Display (Serif): Used for primary headings and prominent text to give a classic, sophisticated look.
- Inter (Sans-serif): Used for body text, labels, and UI elements for clean, modern readability.

2. TECH STACKS USED
---------------------------------------------------
- Frontend (Client-side):
  - HTML5 (Structure)
  - CSS3 (Styling, custom animations, glassmorphism effects)
  - Tailwind CSS (Utility-first CSS framework via CDN for rapid UI development)
  - Vanilla JavaScript (Form validation, navigation, DOM manipulation)
  - Chart.js (Data visualization in the admin dashboard)
  - Chart.js DataLabels Plugin (For displaying values on charts)

- Backend (Server-side):
  - PHP (Server logic, session management, API endpoints)
  - PDO (PHP Data Objects for secure database interactions)

- Database:
  - MySQL / MariaDB (Relational database storing feedbacks and admin accounts)

3. SYSTEM CAPABILITIES & FEATURES
---------------------------------------------------
- Guest Feedback Form:
  - Beautiful, responsive "glassmorphism" design with nature-inspired colors (pine green, gold).
  - Captures guest details: Name, Room Number, Check-out Date, Nationality.
  - Collects 1-10 numerical ratings for: Cleanliness, Amenities, Location, Service, Value, Overall Experience.
  - Asks contextual Yes/No/NA questions (e.g., Staff helpfulness, Bar experience).
  - Captures open-ended text comments for detailed feedback.

- Admin Panel:
  - Secure authentication system for authorized personnel.
  - Dashboard: View key metrics like Total Feedbacks, Average Net Promoter Score (NPS), and recent submissions.
  - Filtering & Export: Filter the feedback list by date, room, or nationality and export data to CSV.
  - View Details: Read the complete submission of individual guests.
  - Analytics: Visual charts showing rating distributions, historical trends, and category performance breakdown.
  - Reports: Generate customized, printable reports summarizing feedback over specific date ranges.

- Super Admin Panel:
  - Specialized secure area for managing regular admin access.
  - Account Management: Create new admin accounts, activate/deactivate existing accounts, and reset passwords to maintain security.
